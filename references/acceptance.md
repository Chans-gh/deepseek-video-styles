# 验收规范：什么叫"这条风格做成了"

> 三个层次，缺一层就不算过关：**技术合规 → 视觉成立 → 节奏可用**。
> 技术不合规的不算交付；视觉不成立的不算配方；节奏不行的只算样片。

---

## 一、技术合规（机器可判，必须 100% 通过）

| # | 检查项 | 判据 | 怎么查 |
|---|---|---|---|
| 1 | 确定性 | 同一 `t` 渲染两次，PNG 逐字节相同 | 渲染两次同 t，`shasum` 比对 |
| 2 | 帧数 | 输出帧数 = fps × duration | `ls frames | wc -l` |
| 3 | 尺寸 | 每帧 = `__meta.width × height` | `sips -g pixelWidth` 或 PIL |
| 4 | 无坏帧 | 不存在全黑/全白/纯色帧（delta < 0.5） | ffmpeg `select=gt(scene,0.0001)` 统计动态帧 |
| 5 | 动态帧比例 | ≥ 70%（纯字幕类可放宽到 50%） | 同上 |
| 6 | 单帧耗时 | < 16ms（复杂场景 < 40ms 可接受，但需说明） | `console.time` + 页面内统计 |
| 7 | 无外部依赖 | 断网渲染仍成功 | 断网或 `--disable-background-networking` 下跑一遍 |
| 8 | 无黑名单 API | 源码 grep `Math.random|Date.now|requestAnimationFrame` | grep |
| 9 | 双画幅 | 16:9 与 9:16 各出一版，各自满足 1–8 项 | 分别跑 `--aspect 16:9` / `--aspect 9:16` |
| 10 | 无跨区溢出 | 每个区块内容在其坐标范围内，无压字/出血 | 抽帧目视 + 端点坐标核对 |

第 4 条最容易被忽略：模型经常在 `t` 超过某个值后就没内容了，最后 2 秒是静止画面。
经验阈值：动态帧低于 60% 基本可以断定时间轴没铺满；60–75% 属于"能动但没内容"，也要查。

---

## 二、视觉成立（人工/视觉模型判，1–10 分）

五个维度，各 2 分：

| 维度 | 2 分标准 | 常见扣分 |
|---|---|---|
| **风格辨识度** | 遮住标题，一眼能说出是什么风格 | 只有颜色像，结构不像 |
| **材质/质感** | 关键材质（纸、金属、玻璃、荧光）有正确的细节层级 | 用渐变冒充材质 |
| **版面** | 画面有主次，留白和密度有安排 | 内容堆一角、大面积空白 |
| **细节自洽** | 边缘、阴影、光晕、字距没有硬伤 | 锯齿、字宽漂移、元素重叠 |
| **完成度** | 看起来像"做完的"，不像"示例" | 缺收尾、缺氛围层 |

### 判定阈值

| 分数 | 处理 |
|---|---|
| ≥ 7 | 可交付 |
| 5–6 | 可修，列出具体扣分项再改一轮 |
| < 5 | 换技术路线，不要在第 4 版之后继续硬改 |

**经验**：同一路线改 3 版没有跨过 6 分，就该换路线。笔触型风格最容易陷在这里——程序近似笔触，越改越像贴图。

---

## 三、节奏可用（看联系表 + 成片）

| 检查 | 标准 |
|---|---|
| 信息高潮 | 6 秒片 ≤ 3 个，且间隔 ≥ 1.2s |
| 变化频率 | 每 0.15–0.2s 有可见变化 |
| 开场 | 前 1 秒要能看出"这是什么" |
| 收尾 | 最后一帧必须是一个稳定构图，不能停在一半 |
| 循环 | 标"无缝循环"的风格，首末帧必须像素一致 |

---

## 四、抽帧规范

每次验收固定抽 5 帧，写在配方文档里：`t = 0.5 / 1.5 / 3.0 / 4.5 / 5.9`（6 秒片）。
无缝循环类另加首末帧对比。批量产出的联系表用 `scripts/tools/sheet.py`。

---

## 五、失败归因表（出问题先查这里）

| 症状 | 最可能原因 | 处理 |
|---|---|---|
| 画面全灰/全糊 | 用渐变代替材质 | 加"多层 + 噪声 + 硬边"三层结构 |
| 边缘锯齿/梳齿 | 路径采样步长太大、`lineTo` 密采样 | 改 Catmull-Rom 平滑 |
| 像素级错位 | 方块字符等宽漂移 | 逐字定点 `x + i*cellW` |
| 实心块里出现网格/细缝 | 固定字宽 ≠ 字形宽度；或矩形坐标是小数 | `measureText` 实测格宽 + 矩形边缘取整 |
| 字标里有重影/双线 | 用了 `╔╗║═` 双线框线字符 | 换 5×7 像素字模，每格一个矩形 |
| 竖屏下方大片空白 | 只把横屏版面等比缩放 | 竖屏单独排一套版面表，追加区块 |
| 竖屏元素打架/压字 | 只挪了 y 没重算行高 | 行高、字号、列数按画幅分别给 |
| 内容堆左上 | 没给版面坐标表 | 补第三节的坐标表 |
| 后半段静止 | 时间轴只写了开场 | 分镜表铺满到 `duration` |
| 每帧都不一样 | 用了 `Math.random` | 换 `mulberry32(seed)` |
| 渲染 10 分钟 | 每帧重算纹理/渐变 | 预烘焙到离屏 canvas |
| 报 `Requesting main frame too early` | Chrome 沙箱起不来 | 加 `--no-sandbox` + puppeteer ≥25 |
| 颜色发灰/发脏 | 叠加层用 `source-over` 糊了底色 | 改用 `multiply`/`lighter` 并降 alpha |
| 卡片/面板里横着一条亮线，几秒后自己消失 | 画折线的函数在 `p<=0` 时提前 return，没 `beginPath`，调用方随后的 `stroke()` 把上一步的圆角矩形描了一遍 | 库层 `drawPolyline` 先 `beginPath()` 再判断 |
| 只有坐标轴/刻度，没有数据 | 轴线与柱子用了不同的时间轴 | 轴线进度跟第一根柱同起点 |
| 开场 1 秒像空屏 | 入场时间线拉得太长 | 内容在时长 1/5 内铺满；背景给"亮灯"渐变 |
| 中文标题入场像被横切成两半 | `riseIn` 的遮罩上推，中文只露横笔画 | 中文用 `mask:false`（淡入 + 轻微上浮） |
