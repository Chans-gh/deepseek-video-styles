# 8 一笔画 · One Line

**技术栈** Canvas 2D（Catmull-Rom 过点样条 + 弧长切片）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 绘图区 | 250,120 / 760 见方 | 150,250 / 780 见方 |
| 主标 | 1080,470 / 104px | 84,1260 / 96px |
| 副标 | 1084,540 / 21px | 88,1320 / 19px |
| 页脚 | 96,1002 | 84,1830 |

**时间轴**：0.2 笔尖光点亮起 → 0.3–3.4 一笔画出侧脸（`slice(pts,0,p)`）→ 3.4 收笔螺旋 → 3.8 主标 → 4.2 注释 → 5.0 页脚

**注意事项**

1. 侧脸画了两版才认得出：五官的锚点必须按**真实比例的坐标表**排，凭手感调九次都像怪脸。
2. 收笔的螺旋不能直接接在路径末尾，要先退 8% 再卷进去，否则收笔处有个硬折。
3. 笔尖光点要跟着当前弧长位置走（`D.at(pts, p)`），不能跟参数 t 走，否则会跑在线的前面。

**规格卡**

```text
底色 #F4F1E9 / 墨 #16130F / 强调 #C8402C。
线宽：主线 3.4px、辅助 1.2px；起笔 0.3s，全长 3.1s，匀速收尾。
动作：笔尖光点 → 一笔成形（不可断线）→ 末尾卷入螺旋 → 文字淡入。
禁止：闭合路径填充、多笔、阴影。
```
