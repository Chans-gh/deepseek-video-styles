# 42 极简图解 / 时间轴 · Timeline

**技术栈** Canvas 2D（横轴 ↔ 竖轴两套版式）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 主轴 | 150→1770 @ y640 | x300，420→1660 |
| 年份（上/下） | 486 / 800 | — |
| 标签（上/下） | 560 / 726 | 行宽 660 |
| 轴宽 | 250 | 660 |

**时间轴**：0.2 主轴生长 → 0.6 六个节点依次弹出 → 1.2 年份（上下交错）→ 1.8 标签 → 3.0 主轴补刻度 → 4.0 页脚

**注意事项**

1. 上方节点的"副标"会跑到"标题"上面——上下两栏的基线必须分开算：`up ? ly-26 : ly` / `up ? ly+6 : ly+26`。
2. 竖屏用横轴的坐标会全挤出画布，整块版面要重写（`vertical: true` 走另一套分支）。
3. 节点圆点与轴的交点要留 1.5px 白边，否则圆压线看起来像粘住。
