# 59 综艺节奏扁平 · Variety

**技术栈** Canvas 2D（斜色块 + 白边巨号 + 贴纸 + 逐帧跳动的节奏条）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 巨号数字 | (960,470) 420px | (540,720) 380px |
| 中文 | 132,760 / 92px | 70,1180 / 78px |
| 节奏条 | 96,900 / 1200×110 / 22 根 | 70,1600 / 940×100 / 16 根 |
| 徽章 | (1600,300) r96 | (800,420) r82 |

**时间轴**：0.1 两块斜色块 → 0.5 巨号数字（白描边拍入）→ 1.2 中文 → 1.8 徽章旋转落位 → 2.4 节奏条逐根弹起 → 3.6 页脚

**注意事项**

1. 巨号数字的描边 0.10em 太粗，字腔里出现白斑，降到 0.055em。
2. 节奏条的每根柱子要**逐帧跳**（用 `h2(i, frame)`），跟 t 连续插值会变成一条波浪，不像电平。
3. 斜色块的角度必须一正一负，同向就只是两块歪方块。
