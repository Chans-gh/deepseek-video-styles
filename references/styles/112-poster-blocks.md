# 112 海报色块动态字 · Poster Blocks

**技术栈** Canvas 2D（色块网格 + 套印错位 + 扫带反白）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 色块网格 | 872,96 / 968×888 / 2×3 gap14 | 64,96 / 952×860 / 2×2 |
| 主字 | 96,470 与 96,720 / 250px | 60,1240 与 60,1436 / 196px |
| 扫带 | 96, 宽 1728 | 0, 宽 1080 |

**时间轴**：0.1 网格底色 → 0.4–1.8 六块色块依次翻入 → 1.2 主字（逐字，套印错位 11px）→ 2.6 红色扫带横穿（反白）→ 3.6 副标 → 4.4 页脚

**注意事项**

1. `T1.forEach` 写了两遍，色块叠了两层——批量改文件后必须看渲染结果，语法没错不代表没重复。
2. 文件尾部缺 `</script></body></html>`，浏览器能渲染但截图有时序问题，必须补齐。
3. 套印错位固定 11px（不是随机），Risso 印刷的错位是恒定的。
4. 左下角空：补一条出血红条压住重心。
