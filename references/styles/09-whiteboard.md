# 9 白板讲解 · Whiteboard

**技术栈** Canvas 2D（手绘抖动 `roughPts` + 圈红线 + 板擦笔槽）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 板面 | 56,56 / 1808×968 | 40,40 / 1000×1840 |
| 标题 | 150,210 / 54px | 96,300 / 44px |
| 三行要点 | 150,470 / 30px 行高 66 | 96,700 / 26px 行高 76 |
| 圈重点 | (1120,520) r130 | (540,1250) r150 |

**时间轴**：0.2 板面（含板擦槽）→ 0.4 标题 → 0.9 三行要点逐行手写 → 2.2 箭头 → 2.6 红圈（两圈，第二圈更松）→ 3.6 侧栏小字 → 4.6 页脚

**注意事项**

1. 用 `Math.random` 抖会"沸腾"（每帧不同）且不可复现；`roughPts` 用两个不同频率的正弦叠加，稳且像手。
2. 红圈必须**画两遍**、第二遍起点偏一点、alpha 降到 0.6，单圈太像印刷。
3. 要点行的手写速度要和字长挂钩（每字 0.055s），否则长句像卡住。

**规格卡**

```text
板面 #F7F6F2 / 墨 #22262B / 红 #D23B2E。
字号：标题 54 / 要点 30 / 侧栏 22 / 页脚 16（手写体感觉靠抖动，不靠斜体）。
动作：板面先落 → 每行 0.055s/字 写出 → 红圈两遍 → 侧栏补注。
```
