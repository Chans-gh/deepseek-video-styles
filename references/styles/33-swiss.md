# 33 瑞士国际主义排版 · Swiss

**技术栈** Canvas 2D（只有文字、细线、一个强调色）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 版心边距 | 96 | 64 |
| 巨号数字 | 420px / 基线 520 | 480px / 基线 700 |
| 主词 | 252px，字距 26 → −9 | 200px，字距 18 → −6 |
| 正文 | 3 栏 × 430，行高 27 | 2 栏 × 420，行高 32 |
| 强调色 | `#D8321F` 圆 196 | 圆 142 |

**时间轴**：0.15 栏线 → 0.25 顶栏 → 0.55 巨号升起 → 1.05 红圆扇形展开 → 1.6 主词（字距同时收紧）→ 2.7 中文标题 → 3.05 正文三栏 → 3.6 页脚

**注意事项**

1. 正文 4 行时最后一行会被页脚线切断——正文基线必须和页脚线留 ≥ 20px。
2. 竖屏沿用 3 栏会画到画布外：正文列数要跟版面表走，不能跟数组长度走。
3. 巨号与红圆在竖屏会互相压住，竖屏要把圆右移、把号收小。

**规格卡**

```text
版面：1920×1080，版心 96；12 栏；基线 29px。
层级：编号 420px（唯一例外级的字号）/ 主词 252px / 中文标题 56px / 正文 18px / 页脚 16px。
颜色：纸 #F2EEE5、墨 #14120F、强调 #D8321F、灰 #7D766B。
动作：栏线先出 → 巨号遮罩上浮 → 红圆按扇形扫开（1.1s）→ 主词上浮同时字距从 26 收到 −9 → 正文按栏错峰。
禁止：自动居中、多字重混排、圆角、阴影、渐变。
```
