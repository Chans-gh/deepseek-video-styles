# 92 玻璃拟态极光 · Glassmorphism

**技术栈** Canvas 2D + 离屏 backdrop blur
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 主卡 | 120,392 800×472 r28 | 64,452 952×564 |
| 副卡 | 976,392 820×264 | 64,1048 952×392 |
| 条卡 | 976,690 820×174 r24 | 64,1480 952×200 |
| 标题 | 74px @ y262 | 62px @ y330 |
| 柱数 | 30 | 24 |

**时间轴**：0.05 胶囊 → 0.10 标题淡入 → 0.35 副标 → 0.30 主卡 → 0.50 副卡 → 0.70 条卡 → 0.75 柱+轴 → 0.80–1.65 折线生长 → 1.00 底部三格 → 1.35 页脚 → 4.2 边缘流光

> 卡片别晚于 1.0s 进场：主卡 1.0s 到位、条卡压到 1.65s 前，开场就不空；晚了前 1 秒是空屏。
> 6 秒的片子，入场最多占 1/6，超过就是"没内容"。

**卡片 A 内部纵向节奏**（顶部文字块用固定偏移，图表区随卡片高度拉伸）

| 元素 | 偏移 | 说明 |
|---|---|---|

**注意事项**

1. Canvas 没有 `backdrop-filter`：把背景层单独画到离屏画布，取卡片区域做 `blur(34px)`，再用圆角矩形裁回去。
2. 玻璃 = 模糊 + 半透明白（上亮下暗）+ 1px 渐变描边 + 投影，四件缺一不可；只画半透明矩形是塑料片。
3. **顶部高光别单画一层**。单独一层渐变带在下缘会留一条硬边，横穿整张卡片，看起来像一条数据线。把提亮并进卡片填充渐变（.155 → .062 → .042）最稳。
4. **坐标轴必须跟数据同源**。柱子用 `seq(t,i,0.75,…)` 长出来，轴线却用卡片出场进度，前 0.5s 会只有一条基线和三个悬空的刻度。轴线进度要和第一根柱同起点。
5. **柱状图要铺满卡宽**。柱子从 `x+300` 起会在左下角留一块空洞；要从内边距起、`slot = iw/n`，刻度对齐首/中/末柱。
6. 数字旁的"秒"不能写死偏移：`c.x+44+190` 会让 `s` 压在 `4` 上，必须 `measureText` 之后再放。
7. 卡片 C 不能只放一行字：174–200px 的高度撑不住。用四层合成示意（模糊/填充/描边/投影各一枚 30px 图形 + 编号 + 名称）填满。

**规格卡**

```text
背景：深蓝 #0A0C18 → 紫 #161029，叠 4 个径向光斑（紫/青/粉/薄荷），lighter 混合，缓慢漂移；开场 0.9s 内整体亮度 0.45→1.0（"亮灯"，避免纯空屏）。
卡片：圆角 28；背景模糊 34px；填充 rgba(255,255,255,.155→.062→.042) 自上而下；1.2px 渐变描边（上 .55 下 .10）；投影 blur 60 / y 26 / α .55。
文字：#FFF 0.97 主 / rgba(255,255,255,.5) 次。
动效：卡片上浮 46px（outQuart），内容错峰 0.08–0.10s，结尾一道 320px 宽的边缘流光。
```
