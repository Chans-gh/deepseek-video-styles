# 24 装饰艺术 · Art Deco

**技术栈** Canvas 2D（切角矩形 + 放射线 + 扇饰 + 三级阶梯基座）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 双线框 | 外 46 / 内 66 | 外 38 / 内 56 |
| 放射线 | r0 150 → r1 900，40 根，张角 1.5 | r0 130 → r1 760，34 根 |
| 主标 | 610 / 132px，字距 30→14 | 见竖屏版 |
| 阶梯拱 | base 892 / 620 宽 / 6 级 | base 1400 / 620 宽 |

**时间轴**：0.1 双线框 → 0.3 放射线展开 → 0.9 阶梯拱（6 级逐级升起）→ 1.4 日冕扇饰 → 1.9 中文小标（字距 16）→ 2.4 主标（字距 30 收到 14）→ 3.1 分隔线 → 3.5 副标 → 4.2 两侧人字柱

**注意事项**

1. 拱门不要画弧线：Art Deco 的拱是**层层收进的台阶**，每一级都要落地。画成浮空细棍就散了。
2. 放射线从 r0 开始会在中心留一圈硬边圆盘；r0 处叠一层径向渐变到透明才接得上。
3. 竖屏底部空了 1/3：横屏的构图直接竖过来必空，竖屏要补内容——这里补的是节目单（4 行 + 虚线引导）。

**规格卡**

```text
底色 #0E0B07 / 金 #C8A24A / 米 #EDE3CC / 深金 #7A5F22。
线：外框 2px 双线，内框 1px；放射线 1px alpha 0.22，越外侧越淡。
字号：主标 132（字距收到 14）/ 中文小标 44（字距 16）/ 副标 22。
动作：框 → 射线 → 台阶 → 扇饰 → 字（字距同时收紧）→ 人字柱。
禁止：圆角、无衬线粗体、渐变填充。
```
