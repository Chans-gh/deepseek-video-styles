# 36 动态文字排版 · Kinetic Type

**技术栈** Canvas 2D（巨型字压边 + 两行反向滑入 + 字距收放）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 巨型字 | (1612,512) 620px | (700,1200) 520px |
| 第一行 | y470 / 176px 字距 −22→4 | y560 / 108px |
| 第二行 | y648 / 80px x372 字距 14→−4 | y700 / 52px |
| 分隔线 | 118,866 / 700 宽 | 74,1592 / 540 |

**时间轴**：0.1 巨型红字压右缘 → 0.5 第一行从右滑入 → 1.0 第二行从左滑入 → 1.6 两行字距对向收放 → 2.6 红线 → 3.0 标签 → 3.8 页脚

**注意事项**

1. 巨型红字压住了白色文字——巨型字要压**右缘**（cx 1612），白字收窄到 `W*0.72` 的裁切区。
2. 中文标签做遮罩上浮会被横切（中文没有下伸部，`mask` 基线算法对汉字不成立），中文一律 `mask:false`。
3. 两行必须**反向**滑入（一行右进、一行左进），同向就只是"两行都在动"。
