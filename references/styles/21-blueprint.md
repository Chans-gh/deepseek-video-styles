# 21 蓝图 / 工程制图 · Blueprint

**技术栈** Canvas 2D（线稿 + 剖面线 + 尺寸标注）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 图框 | 外 38 / 内 48 双线 | 外 34 / 内 44 |
| 正视图 | (520,470) R200，8×Ø48 均布 Ø300 | (470,700) R224 |
| 剖视 | cx1000，厚 72，孔 104 | cx470，厚 60，孔 80 |
| 尺寸线 | 水平 y762 / 垂直 x268 | y962 / x152 |
| 标题栏 | 1250,780 622×226 | 64,1616 952×180 |

**时间轴**：0.05 网格 → 0.2 图框 → 0.45 外圆/内孔 → 1.5 螺栓孔逐个弹出 → 1.7 剖视 + 剖面线 → 2.5 水平尺寸 → 2.8 垂直尺寸 → 3.1 厚度尺寸 → 3.2 技术要求 → 3.6 标题栏

**注意事项**

1. 只有两块剖面线板子，看起来是两个浮空方块；必须补外形虚线或 A—A 剖切标记，读者才知道是同一个零件。
2. `Ø` 在等宽字体里可能回退成别的字形，改用无衬线。
3. 页脚基线要留在内框以内（内框 1032，页脚 1016），否则文字压线。
4. 竖屏正视图、尺寸线、剖视、技术要求四段挤在一起，纵向间距必须重排而不是等比压缩。

**规格卡**

```text
底色 #0C3E6B → #082A4C 径向；网格 40px、α0.055；线 #D8EAFA，强调 #7FD4FF。
线宽只有两档：0.8 细线 / 2.2 轮廓。
尺寸标注 = 引出线 + 尺寸线 + 45° 斜杠 + 数值（无衬线）。
剖切区必须有 45° 剖面线（间距 11px）。
图框双线；标题栏四行三列，含图号/比例/材料/日期/单位。
```
