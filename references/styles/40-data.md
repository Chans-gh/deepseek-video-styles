# 40 数据叙事 · Data Storytelling

**技术栈** Canvas 2D
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 图表区 | 150,392 · 1596×486 | 96,620 · 920×740 |
| 大数字 | 118px，右对齐 1800 | 108px，左对齐 64 |
| 峰值注解 | 250×96 圆角框 | 同 |
| 底部统计 | — | 3 格，1500 |

**时间轴**：0.1 网格 → 0.15 标题 → 0.6 数字滚动 → 0.9 主折线（按路径长度生长）→ 1.9 虚线第二序列 → 2.7 峰值注解 → 3.3 统计格 → 3.9 游标横扫

**注意事项**

1. 折线生长不能用 `lineTo` 逐点加，会跳点；要按**路径长度**插值出最后一个点。
2. 只画线不画 Y 轴刻度，读者无法读数——刻度是可信度，不是装饰。
3. **末段必须留一个持续动作**：折线长完后若整屏静止，片子会像卡住。补一条随 `t` 移动的上扫读线和末端游标。

**规格卡**

```text
坐标系先定：绘图区 x/y/w/h，值域 0–100，X 轴 24 点、每 2 点一个时间标签。
主序列 3.4px 实线 + 渐隐面积（0.28 → 0）；副序列 2.2px 虚线 + 流动 dash。
注解：竖虚线 + 实心点 + 250×96 信息框（PEAK / 数值 / 时刻），框不得压住折线。
必须有 Y 轴刻度与单位。
```
