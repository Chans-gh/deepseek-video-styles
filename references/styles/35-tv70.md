# 35 70 年代电视片头 · TV70

**技术栈** Canvas 2D（斜彩带 + 星形擦除 + 白边黑字）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 彩带 | h168 / 长 2600 / 斜切 420 | h120 / 1600 / 300 |
| 主标 | cy520 / 180px | cy940 / 130px |
| 副标 | y660 / 34px 字距 10 | y1040 / 26px |

**时间轴**：0.2 三条斜彩带依次扫入 → 1.2 星形擦除 → 1.8 主标（白边黑字，粗描边）→ 2.8 副标 → 3.8 页脚

**注意事项**

1. 星形擦除的 `clip` 路径要做成多边形星（10 点），圆润的星会像闪光贴纸。
2. 白描边用 `strokeText` 叠在 `fillText` 下面，`lineJoin='round'`，否则尖角处有黑毛刺。
3. 斜带倾角统一 −18°，一条一个角度就会散。
