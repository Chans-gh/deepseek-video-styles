# 43 说明书 / 步骤图 · Manual

**技术栈** Canvas 2D（线稿零件 + 螺钉旋紧弧 + 尺寸标注）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 三格面板 | 96,268 / 1728×620 / 3 列 gap40 | 64,320 / 952×1340 / 1 列 |
| 图注 | 面板下 44 | 下 38 |
| 右上元信息 | 1824,128 | 1016,196 |

**时间轴**：0.15 标题 → 0.4 三格面板框 → 0.7–2.6 三格零件依次画线稿 → 1.6 螺钉旋紧弧（90°）→ 2.4 尺寸标注（带箭头）→ 3.2 图注 → 4.0 页脚

**注意事项**

1. 尺寸标注的箭头会压在零件上——标注线要放在零件包围盒外 24px，且箭头只画单侧。
2. 竖屏不能把三格横排直接改成三格竖排：改单列后每格高度翻倍，图注的 dy 要重算。
3. 线稿的"技术感"来自**统一线宽**（1.6px）+ 圆角 0 + 纯黑白，加一点灰度就变插画。
