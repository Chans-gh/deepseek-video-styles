# 79 生成式抽象 / 音乐可视化 · Sound Organism

**技术栈** Canvas 2D（径向频谱 + 平滑包络 + 粒子）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 环心 / 内半径 | (960,520) r0 268 | (540,900) r0 232 |
| 频谱长度 | 208 | 186 |
| 柱数 | 96 | 80 |
| 拍速 | 128 BPM | 128 BPM |

**时间轴**：全程连续，0–1.0 环从 0.9 撑开，每拍（0.469s）整圈泵一次

**注意事项**

1. 没有音轨，"像有音乐"要靠三件事：**节拍包络**（每拍尖峰 + 快速衰减）、**分频**（低频堆正上方，高频散两侧）、**余晖**（粒子拖尾）。
2. 原始频谱值大多挤在 0.5~0.75，直接画就是一个圆。必须按环上一周的标准差**归一化**一次，才有峰谷。
3. 高频不能靠连续噪声：96 个采样点上 53 周会直接拍成噪点，改用逐柱哈希给"刺"。
4. 柱要尖（像频谱）、包络要顺（像生物），两者**必须是两条数组**，共用一组不是长角就是糖水。
5. 一圈彩柱是 Winamp 预设感；柱只当内纹，主角是柱尖连成的闭合曲线。
