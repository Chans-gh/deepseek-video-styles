# 113 颗粒渐变开场 · Grain Gradient

**技术栈** Canvas 2D（多团径向渐变叠加 + 胶片颗粒 + 焦点拉入）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 眉标 | 960,404 / 17px 字距 0.52→0.24em | 540,902 |
| 主标 | 960,556 / 156px | 540,1058 / 134px |
| 英译 | 960,636 / 22px 字距 0.10→0.62em | 540,1138 |
| 副标 | 960,706 / 24px | 540,1216 |

**时间轴**：0–1.6 渐变从黑里亮起 → 1.1 眉标（字距收）→ 1.9–3.6 主标焦点拉入（模糊 26→0，缩放 1.075→1）→ 2.9 英译（字距展开）→ 3.6 副标 + 细线 → 4.4 页脚

**注意事项**

1. 只有两色的渐变就是 PPT 底，必须有**第三色**（这里是珊瑚色）+ 一道水平光带。
2. 颗粒要压在**字上面**（压在字下面就像贴纸），alpha 0.155。
3. 焦点拉入如果叠"柔光层 + 实层"，过渡帧会出现两层虚影，像渲染坏了；只画一层。
4. 全片套 1.045 的极缓推近，不推会死板。
