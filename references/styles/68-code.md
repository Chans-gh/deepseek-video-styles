# 68 代码编辑器叙事 · Code

**技术栈** Canvas 2D（词法着色 + 逐行打字 + 终端输出 + 预览环）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 窗口 | 120,150 / 1240×780 | 52,210 / 976×800 |
| 代码 | 19px / 行高 34 / 行号槽 62 | 19px / 36 / 56 |
| 终端 | 120,792 / 1240×168 | 52,1032 / 976×190 |
| 预览 | 1400,150 / 400×440 | 52,1250 / 976×340 |

**时间轴**：0.2 窗口 → 0.6 逐行打字（每行 0.09s）→ 3.0 终端输出 → 3.6 预览环闭合 → 4.4 页脚

**注意事项**

1. 圆角矩形用了不存在的 `D.ctxRound`，改用 `C.roundRect`。
2. 窗口高度按 `CODE.length` 算，不要写死——写死会留 3 行空行。
3. 竖屏预览位置用了 `L.aspect`（不存在），版面里应该读 `s.aspect`。
4. 词法着色的关键字表要包含 `=>` 这种符号 token，否则箭头前后颜色断层。
