# 44 暗色科技发布会 · Keynote

**技术栈** Canvas 2D（光柱 + 轮廓光板 + 滚数参数）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 光柱 | x1180 / 宽 320 | x380 / 320 |
| 光板 | (1230,560) 300×560 旋转 −0.10 | (540,560) 260×470 |
| 主标 | 120,520 / 176px | 64,900 / 128px |
| 参数四行 | 1590,360 / 行距 82 | 64,1230 / 行距 104 |

**时间轴**：0.3 光柱升起 → 0.7 光板（带轮廓光）→ 1.2 主标 → 1.8 副标 → 2.4–4.0 四行参数逐个滚数 → 4.6 页脚

**注意事项**

1. 四行参数互相压住：行距 62 不够，改 82；数值基线 `2.2em → 2.9em`；分隔线推到 `3.4em`。
2. 轮廓光板不能靠描边，要靠**一侧的线性渐变**（边缘亮、内侧透），描边会变成贴纸边。
3. 滚数用 `A.counter(t, ...)` 传参数，别在场景里手写插值——手写的那份不能复用。
