# 31 包豪斯 · Bauhaus

**技术栈** Canvas 2D（圆 / 三角 / 半圆 / 方 + 一个无衬线主词）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 红圆 | (520,380) r190 | (330,468) r206 |
| 黑半圆 | (520,620) r190 | (330,694) r206 |
| 黄三角 | 顶点 (1180,176)，底 936–1424 @620 | 顶点 (762,300)，底 596–962 @772 |
| 蓝方 | 1520,176 176×444 | 620,846 342×142 |
| 主词 | baseline 930，150px，字距 −8 | baseline 1262，166px |

**时间轴**：0.1 顶线张开 → 0.45 红圆 → 0.9 半圆抬起 → 1.25 三角（微旋转 −0.09rad 回正）→ 1.6 蓝方推入 → 2.25 主词逐字落下 → 2.8 图例 → 3.5 页脚 → 3.9 竖屏黑带

**注意事项**

1. 主词基线与半圆底部只差 30px 时会压字——主词 150px 时 cap 高约 108px，基线要再往下 60px。
2. `outBack` 缓动会让元素超出目标位置 10%，三角的顶点会溢出上边界，需要预留。

**规格卡**

```text
只用三种基本形：圆、正三角、矩形；只用三原色 + 黑 + 米白纸。
构图允许压叠，但主词必须完整压在空白上。
动作：形状按 0.4s 间隔依次进入，三角入场带 −5° 回正，主词逐字下落 0.055s/字（outBack）。
禁止：渐变、描边、阴影、任何写实纹理。
```
