# 37 象形图运动图形 · Pictogram

**技术栈** Canvas 2D（四格色块 + 关节姿态）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 网格 | 96,286 / 1728×470 / 4 格 | 64,360 / 952×1080 / 2×2 |
| 姿态色块 | 每格一色 | 同 |
| 底部条 | 96,820 / 1728×96 | 64,1520 / 952×200 |

**时间轴**：0.1 标题 → 0.4 四格色块依次落 → 0.9–2.4 四个人物依次进入姿态（跑 / 跳 / 投 / 踢）→ 2.6 底部标签条 → 3.6 页脚

**注意事项**

1. 弯腿比直腿长一倍——`limb()` 必须把腿长按 55/45 拆成大腿小腿，否则一弯就变形。
2. 头与身体之间要补 `neck` 段，缺了就是一颗悬浮的球。
3. 四个姿态只有"跑"和"踢"一眼能认，"举"和"投"挤成一团——**宁可少一个动作，也不要两个分不清的动作**。
