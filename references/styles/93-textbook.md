# 93 1950 年代科学教科书 · Textbook

**技术栈** Canvas 2D（椭圆轨道 + 折线引线标注 + 数据表 + FIG 图注）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 图版 | 96,92 / 1728×896 | 60,120 / 960×1620 |
| 恒星 | (620,540) r46 | (420,760) r40 |
| 轨道 | a380 b210 旋转 −0.24 | a330 b168 |
| 标注栏 | 1120,300 / 19px 行高 34 | 100,1180 / 18px 行高 40 |

**时间轴**：0.2 图版框 + 纸底 → 0.5 恒星 → 0.9 椭圆轨道（虚线，描出 1.2 周）→ 1.4 行星沿轨运行 → 2.2 折线引线 + 标注 → 3.2 数据表 → 4.0 FIG 图注

**注意事项**

1. 轨道是椭圆不是圆，引线要接在椭圆上按参数角算点，按圆心加半径算会飘。
2. 引线要**折线**（先横后斜），直线穿过图形就废了。
3. 复古感来自纸底 + 单色（赭红）+ 字距，不是加噪点。
