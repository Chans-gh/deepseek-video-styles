# 47 UI 形变循环 · UI Morph

**技术栈** Canvas 2D（卡 → 播放器 → 胶囊三态插值 + 黑胶收尾）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 卡 | 760,250 / 400×400 r34 | 240,700 / 600×600 r44 |
| 播放器面板 | 460,240 / 1000×400 r40 | 80,460 / 920×760 |
| 胶囊 | 700,880 / 520×92 r46 | 120,1580 / 840×110 |
| 黑胶 | 中心 960,432 / r372（min 边 ×0.345） | 中心 540,806 / r432（×0.40） |

**时间轴**：0–1.1 卡片 → 1.1–2.1 展开为播放器（`mixRect` 插值）→ 3.7–4.7 收起为胶囊，同时黑胶与封面场压上来 → 4.7–6 胶囊态停留

**注意事项**

1. 播放器面板底部大片空白：面板高 600 里内容只有 400，改 400 并重排内部。
2. 三态之间的圆角、位置、尺寸要**同一个 `mixRect`** 插值，分三套写会在中途跳一下。
3. **终止态不能只剩一个控件**。收成胶囊后 80% 面积没有内容，整屏会像加载失败。下面三种补法都不成立，别走：
   - 大封面虚影 + 同心圆（alpha 0.22）→ 缩略图里完全看不出；
   - 形变残影框 + `01 CARD` / `02 PLAYER` 标签 → 像开发占位框；
   - 单纯压暗 + 颗粒 → 面积还是空的。
   正解是给终止态配同题材的**实体主视觉**：这里用大黑胶（盘体落影 + 34 道沟槽 + 两道旋转反光 + 中心标 `NIGHT FLIGHT`）。唱片有信息量，一眼认出"这是音乐"，反光还会转。
4. **背景必须画在壳体之前**。胶囊态的封面场/黑胶若在壳体后面画，会把胶囊糊掉；所以 `fC` 要在画背景之前就算出来（`p1/p2/fC` 全部提到 `draw()` 顶部）。
5. 中心标上的字要用 `T.measure` 求宽再居中，0.55em 估宽会偏；`globalAlpha` 与颜色里的 alpha 别重复乘两遍。
