# 67 科幻 HUD · Sci-fi HUD

**技术栈** Canvas 2D + 合成辉光（离屏画布 → blur → lighter）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 圆心 | (960,548) | (540,940) |
| 环半径 | 148 / 262 / 386 / 512 | 122 / 208 / 300 / 392 |
| 左栏 | 92,300 320 宽，6 行 | 56,300 420 宽，4 行 |
| 频谱 | 1500,300 330×190，26 柱 | 56,1430 700×150 |
| 锁定框 | (1236,348) 92×92 | (760,700) |

**时间轴**：0.1 顶栏 → 0.25 四层环 → 0.6 角度刻度（按角度扫开）→ 1.0 十字准星 → 1.1 左栏 → 1.5 频谱 → 1.4 中心读数 → 3.3 目标锁定 → 全时段：雷达扫描 + 整屏扫描行 + REC 闪烁

**注意事项**

1. 扫描余晖用 30 个扇形叠加会糊成一整块亮三角——要压到 22 个、α 0.075，并用指数衰减。
2. HUD 的"可信"来自刻度与对齐：每 5° 短刻度、每 30° 长刻度，缺了就只是发光圆圈。
3. 只有入场动画的话后段会静止（53/144），需要常驻运动：扫描行 + 数值抖动 + 指示点闪烁。

**规格卡**

```text
底色 #04070C；主色 #4FE3FF；警示 #FFB44A；网格 80px α0.3。
环：4 层同心圆，半径 148/262/386/512；外圈 72 个刻度（每 6 个加长）。
扫描：22 段扇形，α = 0.075·(1−i/22)^1.6，速度 1.15rad/s。
数据：左栏 6 行（名称/数值/条），右栏 26 柱频谱。
合成：离屏画布 → blur(9px) → lighter 0.5 → 叠原图 → 扫描线 → 暗角。
```
