# 55 16-bit 像素平台 · Platformer

**技术栈** Canvas 2D（480×270 离屏 + 整数放大 4×）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 离屏 | 480×270 | 270×480 |
| 地面 | y196 | y372 |
| 主角 x | 160 | 86 |
| 移速 | 60 px/s | 54 px/s |

**时间轴**：全程滚动（三层视差），0.8 首个金币 → 2.0 跳跃过坑 → 3.4 第二个坑 → 4.4 旗杆

**注意事项**

1. 离屏画布是复用的，**不 `clearRect` 上一帧的地面会留在坑里**，坑就"没挖开"了。清屏 + 先铺坑底土色。
2. 砖缝的横线会横穿坑口，要按坑的 x 区间跳过。
3. `imageSmoothingEnabled = false` 必须同时设在离屏和 blit 两处，漏一处就是糊的。
4. 天空用 3 档 Bayer 抖动会出彩色带，改 6 档。
5. 金币要纯圆 + 一个高光点。四角八边形像金条，不像金币。

> 完整可运行源码见 `assets/examples/`。
