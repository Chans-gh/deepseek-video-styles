# 77 抽象品牌片 · Liquid Chrome

**技术栈** WebGL2 全屏着色器（底层）+ Canvas 2D（字标层）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 字标 | (960,610) 104px 字距 0.52→0.24em | (540,980) 96px |
| 厂标 | (960,470) r54 | (540,810) r62 |
| 副标 | 960,700 / 17px | 540,1082 |
| 页脚 | 96,992 | 72,1822 |

**时间轴**：0–1.4 只有材质（fbm 域扭曲 + 棚拍环境反射）→ 1.4–5.6 一道横扫光带 → 2.1 厂标 → 2.6 字标从中心向两侧张开、字距同时收 → 3.5 副标 → 4.4 页脚

**注意事项**

1. 虹彩不能铺满全幅：那是塑料油膜。铬的可信度靠**棚拍环境三段**（天光 / 一道灯带 / 地面反射），虹彩只在掠射角留 0.42 的权重。
2. 法线不要用三次采样求差分——`dFdx/dFdy` 直接吃高度场的屏幕空间导数，省两个 fbm（约 60% 算力），边缘还更锐。
3. `preserveDrawingBuffer` 必须 `true`，否则 puppeteer 截到的是空白；`antialias` 必须 `false`，swiftshader 下 MSAA 让 1080p fbm 慢 3 倍。
4. 竖屏中心压暗不能用固定阈值：竖屏 `p.x` 只有 ±0.28，`abs(p.x)<0.64` 会让整幅都落进压暗区，变成一条灰带。用归一化坐标（`gl_FragCoord/u_res`）。
5. 厂标用外环 + 四角凹弧星。缺口环 + 菱形会像一只眼睛。

> 完整可运行源码见 `assets/examples/`。
