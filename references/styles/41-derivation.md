# 41 公式推导讲解 · Derivation

**技术栈** Canvas 2D（逐字公式排版 + 单位圆 + 波形描迹）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 三行公式 | 120,272 / 60px 行高 112 | 76,300 / 46px 行高 96 |
| 单位圆 | (1152,646) r154 | (330,1012) r152 |
| 波形 | 起点 = 圆右缘，长 500 高 154 | 长 520 高 152 |
| 符号面板 | 1010,158 / 760 宽 4 行 | 76,1400 / 928 宽 |

**时间轴**：0.5/1.5/2.6 三行公式逐字打出 → 1.1 圆画出 → 2.0–4.4 半径向量从 0 转到 π → 波形同步描出 → 3.2 注释 → 4.5 结论块 → 5.0 图例

**注意事项**

1. 逐字推进不能"每个片段各乘一个 p"，那样第三行会只冒出一个"+"。要先把片段摊平成字符数组，再用全长的 p 切。
2. 单位和波形必须**同点同高**交接：波形起点放在圆的右缘、y 用同一个 sin 尺度，观众才信这是同一个东西。
3. 圆的右缘同时标 "1" 和波形的 "0" 会叠成一个黑疙瘩，删掉一个。
4. 竖屏下 `p.x` 只有 ±0.28，压暗区的横向范围必须用归一化坐标算，否则整幅宽度都落在压暗里。
