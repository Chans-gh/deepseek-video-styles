# 115 白色目录册 · Catalog

**技术栈** Canvas 2D（1px 线稿台灯 + 点线引导规格表 + 巨号编号）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 巨号编号 | 100,900 / 300px | 62,700 / 210px |
| 台灯 | (780,560) 尺度 300 | (540,1220) 250 |
| 规格表 | 944,470 / 17px 行高 46 / 宽 620 | 70,1450 / 16px 行高 56 |
| 品牌 / 页码 | 96,108 与 1824,1020 | 64,160 / 1016 |

**时间轴**：0.2 品牌行 + 页码 → 0.4 巨号编号 → 0.8 品名 → 1.0–2.4 台灯线稿（灯罩 → 灯杆 → 底座 → 电线）→ 2.2 规格表（点线引导逐行）→ 3.4 价格 → 4.2 页脚

**注意事项**

1. 尺寸线压在规格表上——尺寸线移到左侧并旋转 90° 标注。
2. "吊灯"其实画成了台灯，名字和图必须一致，改叫「台灯」。
3. 灯罩下沿敞口会露成一根线，要补罩口线 + 完整灯泡圆，否则灯罩像两个三角形。
4. 目录册的"贵"来自 1px 线宽 + 大量留白 + 点线引导，不加阴影不加圆角。
