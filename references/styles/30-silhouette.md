# 30 剪影剧场 · Silhouette

**技术栈** Canvas 2D（四段渐变天空 + 三层剪影 + 松树 + 走人）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 太阳 | (1330,430) r110 | (700,760) r96 |
| 地平线 | 640 | 1080 |
| 人物 | x760 / 高 150 | x420 / 高 140 |
| 主标 | 118,236 / 62px | 70,300 / 52px |

**时间轴**：0.1 天空四段渐变 → 0.5 太阳升到地平线上 → 1.0 远山 → 1.4 中景树 → 1.9 近景树 + 草 → 2.6 人物走入（从画左外走到 x） → 3.4 主标 → 4.4 页脚

**注意事项**

1. 太阳放在地平线下会被山完全挡住——太阳中心必须高于地平线 ≥ r×0.6，且山的最高点要绕开太阳的 x。
2. 人物 base 写 0 会埋进草里；`base = horizon + 20` 才是"站在地上"。
3. 树不要用矩形叠：三段矩形会像房子。松树要**上窄下宽的三角叠加**，每层左右各缩 18%。

**规格卡**

```text
天空 #1B2140 → #3E3A63 → #8C5A6B → #E0916B（四段，不得少于四段）。
剪影三层：#12131F（远）/ #0C0D16（中）/ #05060B（近），越近越黑。
动作：天光 → 太阳 → 三层剪影由远及近 → 人物走入 → 字。
```
