**技术栈** Canvas 2D（主数字 + 柱状图 + 走马灯）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 主数字 | 88,610 / 250px | 56,660 / 210px |
| 柱图 | 780,400 / 1000×420 / 7 根 | 见竖屏版 |
| 走马灯 | y940 / 高 74 / 20px | 见竖屏版 |

**时间轴**：0.2 栏头 + 日期 → 0.5 标题 → 0.9 主数字滚数 → 1.6 柱状图逐根生长 → 2.6 说明 → 3.4 走马灯 → 4.6 页脚

**注意事项**

1. 走马灯文字会从"实时"红块底下穿过——`clip` 要从红块右侧（x=124）起算。
2. 右上角 "+81% vs 2021" 被顶边切掉，标注要下移并左移。
3. 柱状图的最后一根要留出年份标签的位置，否则标签压在柱脚。
