# 66 终端 / ASCII CRT

**技术栈** Canvas 2D（等宽字符网格 + 离屏辉光合成）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

**一句话**：整块画面是一台正在运行的老 CRT 终端，所有信息都是等宽字符。

**适合**：AI / 技术过程演示、黑客感开场、数据监控界面、开发者向内容。

---

## 视觉 DNA

1. **荧光绿单色**：主色 `#7EFF9E`，暗部 `#3A9658`，警示 `#FFD678`，底色 `#04080A`。整片只有这三种颜色 + 黑。
2. **字符网格**：格宽/格高**由 `measureText('█')` 实测得出**，不写死。
   - 16:9：格 15px（字号 25）、正文 18px、标注 15px
   - 9:16：格 15px、列数减到 65（横屏 118）
   - 大字标：5×7 像素字模，每格 = 一个矩形
3. **CRT 三层合成**：
   - 扫描线：每 3px 一条 1.3px 黑线，alpha 0.15
   - 辉光：`filter: blur(5px)` 副本叠 `lighter`，alpha 0.5
   - 暗角：radial，中心透明 → 边缘黑 0.66
4. **刷新带**：宽 260px 的绿色渐变，alpha 0.05，6 秒自上而下扫一遍。
5. **微闪烁**：整屏亮度 ±2.8%，两个不同频率正弦相乘（`sin(51.7t)*sin(12.3t)`），避免规律感。

## 可复制提示词

```text
你是一名擅长纯代码动画的前端工程师。做一支 6 秒、24fps 的短片，风格是「90 年代终端 / ASCII CRT」：
整块画面是一台正在跑日志的老式 CRT 终端。要出两个画幅：1920×1080 与 1080×1920，各排一套版面。

【交付契约】
1. 交付单个 HTML 文件，内联 CSS 与 JS，不联网、不引 CDN、不加载任何外部图片或字体文件。
2. 必须提供：
   const ASPECT = new URLSearchParams(location.search).get('aspect') || '16:9';
   window.__meta = { width, height, fps: 24, duration: 6 };   // 按 ASPECT 取 1920×1080 或 1080×1920
   window.seek = function(t){ /* 画出 t 秒这一帧，从零重绘 */ };
   window.__ready = true;  并在末尾调用一次 seek(0)。
3. 确定性：同一 t 必须得到同一像素。禁止 Math.random / Date.now / performance.now /
   requestAnimationFrame 驱动状态。需要随机时用 mulberry32(固定种子)。
4. 静态部分在初始化时算好，seek 内只做合成，单帧耗时 < 16ms。

【版面】两套版面表，按 ASPECT 取值，不要用缩放实现竖屏。
横屏 1920×1080，外边距 56：
- 顶栏 y 56–102，半透明底条 alpha 0.10，左系统信息 17px，右时钟 17px
- 命令行 y 134，19px，逐字打出 + 光标
- 日志 x 56–1215，y 186–474，12 行 × 25px，18px
- 右监控 x 1394–1864，y 138–444，SIGNAL 12 条 + LOAD 进度
- 波形 x 56–1215，y 505–657，8 行，列数按区宽自动算
- 大字标居中，y 712–912，像素字模，格 30px
- 底部状态条 y 1034–1080，满宽反白，左进度百分比，右 BUFFER 条
竖屏 1080×1920，外边距 44：
- 顶栏 y 44–90；命令行 y 162
- 日志 y 204–468，12 行 × 24px，满宽
- SIGNAL y 532–730（8 条）；LOAD y 774–848
- 波形 y 890–1146（12 行，比横屏更高）
- 大字标 y 1176–1386
- 十六进制转储区 y 1440–1780（竖屏独有，12 行，用来填满纵向空间）
- 底部状态条 y 1874–1920
任何元素不得跨越区块边界。

【视觉 DNA】
- 荧光绿单色：主色 #7EFF9E，暗部 #3A9658，警示用 #FFD678，底色 #04080A。全片只用这三个颜色加黑。
- 扫描线：每 3px 一条 1.3px 黑线，alpha 0.15。
- 辉光：把文字层复制一份做 blur(5px)，用 lighter 叠加，alpha 0.5。
- 暗角：径向渐变，中心透明到边缘黑 0.66。
- 刷新带：宽 260px 的绿色竖直渐变，alpha 0.05，6 秒内从顶扫到底。
- 微闪烁：整屏亮度 0.972 + 0.028 × sin(51.7t) × sin(12.3t)。

【时间轴】
0–0.6s 顶栏与开机行出现（alpha 0→0.9）；
0.35–1.05s 命令行 32 字/秒打出，光标每 0.42s 闪一次；
1.15s 起每 0.16s 出一条日志，共 12 条，出现后 0.15s 内 alpha 爬到 1，其中一条用警示色；
0.9s 起波形常驻并横向滚动；
2.2s 起竖屏转储区每秒落 9 行；
3.0s 起大字标淡入，0.4s 内到 alpha 0.95；
全程保留刷新带与微闪烁。

【实现要求（照做，不要自己发挥）】
1. 所有文字先画到一张离屏 canvas，再整体做辉光叠加；逐字 shadowBlur 会慢 5 倍。
2. 方块字符（█ ░ ▀）不要用字形填充，直接用 fillRect：字形描边抗锯齿会在块之间留细缝。
3. 格宽必须实测：g.font = mono(size); const w = g.measureText('█').width;
   然后用 w * 0.995 作为步进。写死一个"看起来差不多"的字宽，整块图形会变成网点。
4. 矩形边缘取整：x0 = Math.round(x + i*cw), x1 = Math.round(x + (i+1)*cw)，宽 = x1 - x0。
   小数坐标会让相邻矩形各自抗锯齿，放大是一片网格。
5. 大字标用 5×7 像素字模（每个字母 5 列 7 行的 0/1 矩阵），每格画一个矩形。
   不要用 ╔╗║═ 这类 ASCII 艺术字：它们是双线框线字符，在实心块里会飘出两条平行细线。
6. 扫描线用 fillRect 循环绘制，不要用 pattern。
7. 波形列数 = Math.floor(区宽 / 格宽)，不要写死 94 列，否则换画幅就出界。

【自检】交付前逐条回答：
1. 同一 t 渲染两次是否像素一致？
2. 两个画幅分别跑一遍，有无元素越界或重叠？
3. 列出 t=0 / 1.5 / 3 / 4.5 / 5.9 各自画面上有什么。
4. 有无全黑/纯色帧？
5. 放大 3 倍看方块区域，有没有残留的细缝或网格？
6. 单帧绘制耗时多少毫秒？
7. 是否用到 Math.random / Date.now / requestAnimationFrame / 外链？
```

## 实现要点

| 点 | 做法 | 收益 |
|---|---|---|
| 先文字后辉光 | 文字画到离屏 canvas → 模糊副本 → `lighter` 叠加 | 比逐字 `shadowBlur` 快 5 倍 |
| 格宽实测 | `measureText('█')` 反推 advance 与字形高 | 消除字宽漂移与细缝，字号可自由调 |
| 矩形取整 | `round(x0)` / `round(x1)`，宽取差 | 相邻块无缝，放大无网格 |
| 像素字模 | 5×7 0/1 矩阵 → 每格一个 `fillRect` | 字标不依赖字体，换画幅不散 |
| 波形离散化 | 每列一个方块，高度由正弦叠加算出 | 既有抖动感又不会糊 |
| 版面表 | `LAYOUT['16:9'] / LAYOUT['9:16']` | 一个文件出两版，互不干扰 |

## 注意事项

| 坑 | 现象 | 解法 |
|---|---|---|
| 字宽漂移 | 大字标笔画重叠、左右错位 | 逐字定点，字宽由 `measureText` 实测 |
| 固定字宽 → 网点 | 实心块变成一片竖纹 | 步进用字形 advance × 0.995 |
| 小数矩形接缝 | 放大 3 倍能看到淡色网格 | 矩形四边取整，宽高取差 |
| 双线框线字符 | 字标里出现重影/两条平行线 | 换 5×7 像素字模 |
| 元素跨区 | 波形压住右侧数字、字标压住波形 | 列数按区宽算；区块高度单独预留并做溢出回退 |
| 辉光糊字 | 文字发虚 | 辉光 alpha ≤ 0.5、blur ≤ 6px |
| 后半段空 | 6 秒只写了 2 秒内容 | 分镜表铺满到 duration |
| 竖屏下方空 | 只缩放横屏版面 | 竖屏单独排版面表 + 追加区块 |
