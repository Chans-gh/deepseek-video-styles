# 63 1920 年代默片 · Silent Film

**技术栈** Canvas 2D（剪影 + 放映瑕疵）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 画框 | 334,70 1252×940（4:3） | 34,292 1012×1348（竖幅） |
| 月亮 | 0.735w, 0.175h, r=0.058·短边 | 同 |
| 楼群 | 26 栋，高 0.20–0.66h，亮窗密度 34% | 同 |
| 时间轴 | 字幕卡 0–1.28 / 城市 1.28–2.86 / 间幕 2.86–3.84 / 城市 3.84–5.28 / 光圈收 5.28–6 | 同 |

**时间轴细节**：0.12 片头字卡 → 1.24 光圈开 → 1.28 城市横移 → 2.86 硬切间幕 → 3.84 城市 → 5.28 光圈收

**注意事项**

1. 天空用中间调灰会让剪影发闷；要"地平线亮、顶部深"（#7B7466 → #E8DEC6），剪影才立得住。
2. 亮窗按 3.6×5px 画会像星星；要 4.4×6px 并按楼宽算列数，才有"窗格"的感觉。
3. 前景楼与远景楼之间透出亮雾，会形成竖条光柱；雾的 α 压到 0.18，地面提前到 0.93h。
4. 9:16 沿用 4:3 画框会浪费 60% 纵向空间；竖屏要改竖幅取景（1012×1348），不是缩小。

**规格卡**

```text
画框外纯黑；画框内为暖灰正色片（#7B7466 → #E8DEC6，地平线最亮）。
天空：月亮 + 低对比薄云；剪影：楼群纯黑 #0B0A08，部分带退台与天线（天线顶红点闪烁）。
放映瑕疵：门晃 ±1.6px（每帧变）、颗粒 α0.17、闪烁 α0.03–0.075、2–3 条竖向划痕、四角暗角 0.72。
字幕卡：米白 #EFE9DA，中文 0.155h、英文衬线 + 字距，双线花框。
```
