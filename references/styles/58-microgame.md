# 58 微游戏快闪 · Microgame

**技术栈** Canvas 2D（320×180 离屏，6 秒三段硬切）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 离屏 | 320×180 | 180×320 |
| 第一段 | PONG 0–2s | 同 |
| 第二段 | 射击 2–4s | 同 |
| 第三段 | 俄罗斯方块 4–6s | 井宽 13 / 格 12 |

**时间轴**：0 / 2 / 4 秒三个切点，每个切点 2 帧白闪

**注意事项**

1. 俄罗斯方块井口太小、下半屏空：`TW 10→13`、`grid 9→12`。
2. 三段之间必须**硬切 + 白闪**，做淡入淡出就变成"一个片子"而不是"三连击"。
3. 用 Python 批量改这个文件时正则漏掉了右括号，`Unexpected token ','`——切片替换后必须整份语法检查。
