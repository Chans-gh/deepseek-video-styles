# 34 60 年代间谍片头 · Spy Title

**技术栈** Canvas 2D（放射条纹 + 枪膛同心环 + 剪影 + 标题黑带）
**画幅** 16:9（1920×1080）+ 9:16（1080×1920）

| 参数 | 16:9 | 9:16 |
|---|---|---|
| 枪膛 | (960,470) r0 250 → r1 760 / 9 环 | (540,760) r0 200 → r1 780 |
| 主标 | y900 / 96px 字距 26→8 | y1500 / 74px |
| 底带 | y 860–1000 | y 1460–1600 |

**时间轴**：0.1 放射条纹旋入 → 0.6 枪膛外环 → 1.0–2.2 九环由外向内收紧 → 1.4 剪影淡入 → 2.6 标题字距收到 8 → 3.2 副标 → 4.0 黑带

**注意事项**

1. 同心环画成了一圈辐条——循环里 `arc()` 前没 `beginPath()`，九条路径连成一片。
2. 黑环压在深色条纹上直接消失；全部改奶油色 + 降 alpha，靠明度对比而不是靠黑。
3. 枪膛是黑的、剪影也是黑的，两个剪影叠在一起。枪膛改亮底 + 纯黑剪影。
4. 剪影抬手姿态在片头里显得像投降，改直立 + 礼帽；头身之间补 `neck` 段，否则一眼假。
